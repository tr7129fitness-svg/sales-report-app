# 料金表PDF・画像のGoogle Drive保存

このスクリプトは、営業結果レポートで選んだ料金表PDF・画像を、アプリ専用のGoogle Driveフォルダへ保存します。

- フォルダ名: `営業報告アプリ_料金表`
- 初回の保存時に自動作成されます。

Google Drive全体を閲覧する権限は使いません。アプリが作成した料金表フォルダと、その中のファイルだけを扱う `drive.file` 権限を使用します。既存の任意フォルダへまとめたい場合は、作成された料金表フォルダをGoogle Drive上で移動してください。

## 設定

1. Google Apps Scriptで新しいプロジェクトを作成し、`Code.gs` の内容を貼り付けます。
2. `appsscript.json` の明示的な権限を `drive.file` と `script.external_request` に設定します。
3. サービスから Drive API v3 を追加します。共有アップロードキーは不要です。

4. **デプロイ** → **新しいデプロイ** → 種類を **ウェブアプリ** にします。
5. **次のユーザーとして実行** は自分、**アクセスできるユーザー** は「全員」を選択します。
6. 発行された末尾が `/exec` のURLをコピーします。
7. `firebase-config.js` の次の値を設定して、GitHub Pagesへ公開します。

```js
export const driveUploadSettings = {
  endpoint: "https://script.google.com/macros/s/…/exec",
};
```

## 使い方

Googleログインで初回利用申請を行い、管理者が一度承認すると、以降は同じアカウントで自由に利用できます。ログインやアップロードごとの承認はありません。承認済みユーザー全員が全報告と料金表を閲覧・登録できます。

アップロードはFirebase IDトークンと保存済みの承認状態をサーバーで検証します。料金表のリンクはGoogle Driveを直接開き、アプリ内プレビューは表示しません。旧 `?attachment=ファイルID` リンクもアプリへのログイン・承認確認後にGoogle Driveへ転送します。

Driveの共有権限は変更しません。Drive側での閲覧はファイルの共有設定に従い、アプリの利用承認・利用停止とは別に管理する必要があります。

1. 営業報告を入力します。
2. 「料金表」でPDFまたは画像を選び、**Google Driveへ保存** を押します。
3. 保存完了後に表示されたリンクを確認します。
4. 報告全体を保存すると、その営業報告の詳細に料金表リンクが表示されます。

PDF・画像は1点15MBまで、1つの報告につき8点までです。編集や削除をしても、Google Drive上の元ファイルは削除されません。
